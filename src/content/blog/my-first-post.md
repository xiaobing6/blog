这是我用 Astro + Markdown 搭建的第一个博客。整个搭建过程比我想象中要简单很多。

## 为什么选择 Astro

Astro 非常适合内容型网站，比如博客、文档站。它的优势包括：

- **零 JS 默认**：页面默认不加载 JavaScript，加载速度很快
- **内容集合**：可以方便地管理 Markdown/MDX 文章
- **灵活渲染**：支持 SSR、SSG、ISR 等多种渲染模式
- **生态丰富**：可以轻松集成 React、Vue、Tailwind 等

## 这个项目用了什么

- Astro 7
- Tailwind CSS 4
- Markdown 文章
